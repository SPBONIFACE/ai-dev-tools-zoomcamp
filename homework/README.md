## Homework Summaries

### [Homework 1: Spec-Driven Development](./hw1)
* **Goal**: Establish the MAGIE specification framework, PM/SWE/QA role contracts, and groomed issue backlog for the AI Household Chore Manager.
* **Key Artifacts**: [`_docs/plan.md`](../part1-ai-native-development/_docs/plan.md), [`_docs/task-template.md`](../part1-ai-native-development/_docs/task-template.md), and Django chore allocation engine.

### [Homework 2: Full-Stack Application & Issue Automation](./hw2)
* **Goal**: Build and test the full-stack prototype of the System Design Canvas, automate issue synchronization with GitHub API, and validate against contract-first OpenAPI schemas.
* **Key Artifacts**: [`create_issues.py`](./hw2/create_issues.py), [`update_issues.py`](./hw2/update_issues.py), [`openapi.yaml`](./hw2/openapi.yaml), and React/FastAPI prototype.

### [Homework 3: Containerization & Cloud Deployment](./hw3)
* **Goal**: Containerize the Agent Relay service, migrate from SQLite to PostgreSQL, validate concurrency with Playwright, and deploy via Kubernetes manifests and CI/CD pipelines.
* **Key Artifacts**: [`agent-relay/`](./hw3/agent-relay), [`homework-wk3.md`](./hw3/homework-wk3.md), and deployment guides.

### [Homework 4: DevOps, Observability & Incident Response](./hw4)
* **Goal**: Investigate production failures in Order Tracker, add OpenTelemetry tracing/metrics, deploy Prometheus/Loki/Tempo/Grafana, and build an automated on-call incident response agent.
* **Key Artifacts**: [`homework-wk4.md`](./hw4/homework-wk4.md) with questions and solution guides.
